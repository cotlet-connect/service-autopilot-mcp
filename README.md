# Service Autopilot API and MCP server

**Yes, ChatGPT, Claude and other AI agents can work in your Service Autopilot account.** Jobs, schedules, estimates and invoices in Service Autopilot can be handled through Cotlet.dev over MCP or REST.

## What you can ask

> Move rained-out visits to an open day.

> Read each crew's route for the day.

> Add clients with repeating jobs.

> Turn site notes into estimates.

> Invoice jobs and list what is unpaid.

## Connect in 2 minutes

Get your API key at https://cotlet.dev/app and export it as `COTLET_API_KEY`.

### Claude Code

```bash
claude mcp add --transport http cotlet https://cotlet.dev/mcp/v1 --header "Authorization: Bearer $COTLET_API_KEY"
```

### ChatGPT

Settings → Apps → add connector URL `https://cotlet.dev/mcp/v1`, then sign in with Cotlet.dev. No API key needed.

### Cursor

Copy `.cursor/mcp.json` from this repo into your project:

```json
{
  "mcpServers": {
    "cotlet": {
      "url": "https://cotlet.dev/mcp/v1",
      "headers": {
        "Authorization": "Bearer ${COTLET_API_KEY}"
      }
    }
  }
}
```

## Run it locally (stdio)

This repo is a real MCP server. It speaks MCP over stdio, lists its Service Autopilot tools without any key, and forwards every tool call to the hosted Cotlet.dev server. The hosted URL above stays the recommended way. Use this when your client only starts local servers.

```json
{"mcpServers":{"service-autopilot":{"command":"uvx","args":["service-autopilot-mcp"],"env":{"COTLET_API_KEY":"your-key"}}}}
```

Or with Docker:

```bash
docker build -t service-autopilot-mcp .
docker run -i --rm -e COTLET_API_KEY service-autopilot-mcp
```

Tools: `service_autopilot_guide`, `service_autopilot_status`, `service_autopilot_open`, `service_autopilot_read`, `service_autopilot_click`, `service_autopilot_type`, `service_autopilot_close`. Without `COTLET_API_KEY` a tool call answers: "Set COTLET_API_KEY. Get a key at https://cotlet.dev/app".

## Command line

Python 3.10+, nothing else to install. From PyPI:

```bash
pip install service-autopilot-mcp        # or run it once: uvx service-autopilot-mcp connect
service-autopilot-mcp connect
```

Or straight from this repo:

```bash
export COTLET_API_KEY="your-key"
python3 service_autopilot_agent.py connect   # ready config for Claude Code, Cursor, ChatGPT
python3 service_autopilot_agent.py status    # is Service Autopilot ready in your Cotlet.dev account
python3 service_autopilot_agent.py guide     # Service Autopilot screens and sign-in link
python3 service_autopilot_agent.py read      # open Service Autopilot, read the page, close the browser
python3 service_autopilot_agent.py tools     # list Cotlet.dev tools
python3 service_autopilot_agent.py serve     # start the stdio MCP server (same as no argument)
```

## Questions from Service Autopilot users

**Does Service Autopilot have an MCP server or an API?**

The live Service Autopilot page documents Cotlet.dev MCP and REST access for your signed-in account.

**How does Cotlet.dev connect to Service Autopilot?**

Sign in to Service Autopilot in your Cotlet Cloud Browser, then connect your agent over MCP or use the Cotlet.dev REST API.

**What can an AI agent do in Service Autopilot?**

It can read routes, manage jobs, work with estimates and list invoices through the tools documented on the live page.

**How do I connect Service Autopilot to ChatGPT or Claude?**

Add https://cotlet.dev/mcp/v1 in ChatGPT or Claude, then use your connected Service Autopilot account.
